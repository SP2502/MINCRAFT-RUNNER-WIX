# MINCRAFT-RUNNER-WIX

Creeper Runner is a small Minecraft-inspired endless runner game that I made using **HTML, CSS and JavaScript**.

The main idea is simple: **keep running, avoid the obstacles, collect gems and try to get the highest score.**

I made this project mainly to practice JavaScript, game logic, animations and working with HTML Canvas.

---

## 🎮 How to Play

- Press **SPACE** or **↑** to jump.
- On mobile, press the **JUMP** button.
- Avoid obstacles like:
  - 🐱 Cats
  - 🌵 Cactus
  - 🧟 Zombies
  - 🧨 TNT
- Collect 💎 gems to increase your score.
- Try to complete the **200 score mission**.
- Your highest score is saved as your **Best Score**.

---

## ⚡ Power-ups

There are also some power-ups that can help during the game.

- 🛡️ **Shield** — protects you from one obstacle.
- ⏱️ **Slow** — makes the obstacles slower for some time.
- 🧲 **Magnet** — attracts nearby gems.

---

## 🎚️ Difficulty

The game has different difficulty levels:

- **Easy**
- **Medium**
- **Hard**
- **Very Hard**

The speed also increases slowly while playing, but it has a **maximum speed limit** so the game does not become impossible.

I used:

- **HTML** — for the game structure
- **CSS** — for the design and UI
- **JavaScript** — for the actual game
- **HTML Canvas** — for drawing and animating the game
- **Web Audio API** — for simple sound effects
- **LocalStorage** — for saving the best score

No game engine is used.
